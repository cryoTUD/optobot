# 00 Electronics

This ReadMe will show of what is all part of the Electronics module, and what be found inside the module folder.
The electronics module consists of 2 sub-assemblies:
- 00 Control Box
- 00.1 PID Box

The Control Box is the 3d printed box and all its electronic components that together work as the driving computer for the plunger setup. The PID Box is the 3d printed box and all its electronic components that together drive the temperature-controlled cup (module 05). The software and the wiring diagram of the control box and the PID box are discussed [here](../control/README.md). In this folder specifically all the supporting documents can be found for the hardware, and how both the Control Box and the PID box are assembled.

### Assembly instructions Control box
An animation is created that shows how the control box should be assembled. The starting point of the animation is the exploded view above, from which the assembly is reassembled. This animation is created in Fusion 360. 

https://github.com/user-attachments/assets/d88c1d05-55b1-4b23-8b8f-91898be7cf4d

All the electronics are mounted onto the 3d printed boxes with screws. These screws are directly screwed into the 3d printed holes for it. In preparation for this, all the holes of the 3d printed box should first be tapped by hand so that the holes have an internal thread that matches the thread of the screws. By tapping beforehand, the mounting of the electrical components onto the control box is simplified. Important to note is that, in the majority of connections, no nuts are used. The screws are directly mounted into the 3d printed control box.
