# 06 Support structure
The support structure is fully created from Item components. The assembly consists of profiles of varying lengths that, when mounted together, build up the entire support structure. The main function of the support structure is to act as a stable base onto which the rest of the parts and assemblies are mounted. It mainly allows the climate chamber to be mounted above the cup assembly. Within this ReadMe an overview will be provided of how the support structure is built. The following will be discussed:
- General overview of the structure
- Exploded view with parts list
- Assembly animation
- Connection drawing

## Assembly instructions: Support structure assembly
For the Temperature-Controlled cup assembly, a short assembly animation video is shown below.

https://github.com/user-attachments/assets/5b934695-0c28-4650-989e-52fc03c3ef01

In the assembly animation, mainly the order of the assembly steps can be observed. Several profiles are connected through Angle Bracket sets (06-11) or simple Angle Brackets (06-12). In addition to that a total of 20 Automatic-Fastening sets (06-13) from Item are used to assemble the entire support structure. These sets are currently not added to the CAD assembly. To still indicate where they are all used in the assembly, a drawing is created where all the locations of the Automatic-Fastening sets are pinpointed with a respective number from 1-20. Below, this drawing is shown.

In the created Optobot setup, the support structure is bolted onto a metric optical table. This optical table is not included in this publication. By fixing the support structure in place, the entire Optobot assembly becomes more stable. It is therefore highly recommended to fix the support structure in place.
